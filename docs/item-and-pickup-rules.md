# 道具、拾取与使用规则

本文记录《避难所格斗》当前版本的场内道具、资源掉落、拾取、携带、使用和清理规则。
数值以 `src-web/game.js` 的实际实现为准。

## 1. 道具分类

| 分类 | 道具 | 是否写入账号资源 | 拾取方式 | 是否跨关保留 |
| --- | --- | --- | --- | --- |
| 资源 | 金币 | 是 | 靠近自动拾取 | 是 |
| 资源 | 鸡腿 | 是 | 靠近自动拾取 | 是 |
| 资源 | 神奇果实 | 是 | 靠近自动拾取 | 是 |
| 投掷物 | 手榴弹 | 否 | 靠近后按“拾取” | 否 |
| 投掷物 | 战锤 | 否 | 靠近后按“拾取” | 否 |
| 临时强化 | 拳焰道具 | 否 | 靠近自动拾取 | 否 |

账号资源用于成长、技能和招募。投掷物与拳焰属于本关战术资源，重新开始关卡、进入下一关或
返回初始页时会清除。

## 2. 资源掉落

敌人死亡并完成奖励结算后生成资源掉落：

- 每名敌人固定掉落金币，基础数量为 `8 + floor(敌人关卡 × 1.6)`；精英敌人额外增加 `28`。
- 鸡腿按本关鸡腿预算分配给尚未结算的敌人；轮番战中每名敌人掉落 `1` 个。
- 精英敌人必定掉落 `1` 个神奇果实。
- 普通敌人的果实掉落概率为 `min(18%, 2.5% + 敌人关卡 × 0.2%)`。
- 金币、鸡腿和果实只会被同楼层的主角吸附和拾取。

资源距离主角小于 `72` 时会逐渐吸向主角，距离小于 `38` 时自动收入资源数量。关卡胜利时，
仍留在地图上的金币、鸡腿和果实会自动收取，不要求玩家逐个走过去。

正式闯关的最终资源数量以服务端通关结果为准，客户端显示不能替代服务端结算。

## 3. 投掷物生成与携带

普通闯关会根据当前地图长度保留以下预设投掷物：

- `x = 620`：手榴弹；
- `x = 860`：战锤；
- `x = 2350`：手榴弹；
- `x = 3920`：战锤；
- `x = 5200`：手榴弹。

超出当前关卡末端的预设道具不会生成。测试轮番战固定生成一把战锤和一枚手榴弹。

主角同一时间只能携带一种投掷物：

- 搜索范围为主角周围 `82`；
- 靠近可拾取投掷物后，右侧显示“拾取”按钮；
- 拾取后道具挂在主角腰间，按钮变为“投掷”；
- 手榴弹携带次数为 `1`；
- 新战锤初始可投掷 `2` 次；
- 已携带投掷物时不能再拾取另一件投掷物。

受伤、倒地、攀爬、抓住敌人、被敌人抓住以及多数攻击动作期间不能使用拾取/投掷按钮。

## 4. 开门与投掷按钮优先级

暗坑地下房间的石门与投掷物共用相近的界面位置，但遵守以下优先级：

1. 主角靠近尚未打开的石门时，优先显示“开门”。
2. “开门”显示期间隐藏“拾取/投掷”按钮。
3. 离开石门范围后，若主角携带投掷物或附近有可拾取投掷物，再显示“投掷”或“拾取”。

因此，玩家不会因为腰间有投掷物而挡住地下石门操作。

## 5. 手榴弹规则

- 投掷水平初速度：`主角朝向 × 330`；
- 投掷垂直初速度：`330`；
- 飞行寿命：`1.2` 秒；
- 爆炸半径：`155`；
- 对范围内敌人造成 `34` 点基础伤害；
- 普通敌人获得 `570` 基础升力，重型敌人获得 `420` 基础升力；
- 爆炸会把敌人转入被摔飞状态，并根据敌人在爆心左右的位置施加水平速度；
- 已经浮空的敌人会按照当前空中续击衰减规则追加爆炸升力；
- 手榴弹爆炸后消失，不能回收。

手榴弹只影响与手榴弹处于同一楼层的敌人。

## 6. 战锤规则

- 投掷水平初速度：`主角朝向 × 680`；
- 飞行寿命：`0.88` 秒；
- 命中宽度约 `54`，纵向判定约 `48`；
- 命中造成 `16` 点基础伤害；
- 未死亡的敌人会落地并眩晕 `1.55` 秒；
- 战锤命中、飞行超时或飞到世界边缘时，如果仍有剩余次数，会掉回当前楼层；
- 拾回后可以继续投掷，直到剩余次数为 `0`；
- 新战锤总共可以完成两次投掷。

战锤只会命中与战锤处于同一楼层、尚未死亡且未处于摔投飞行状态的敌人。

## 7. 拳焰道具生成与拾取

每张地图生成一个拳焰道具，包括普通闯关、自由游览和测试轮番战：

- 生成在地面层；
- 横向位置在本关可游玩范围内随机选择；
- 生成器会避开暗坑入口；
- 生成器会避开森林树木等地面阻挡物；
- 主角与道具处于同一楼层且距离小于 `42` 时自动拾取；
- 同一时间最多储存一次未释放的拳焰。

拾取后，战斗界面左侧出现独立的“拳焰”按钮。拳焰不占用腰间投掷物位置，也不影响开门、
拾取和投掷按钮。

拳焰按钮沿用普通战斗按键的深色半透明矩形样式，只使用低亮度蓝灰边框进行识别，不使用
高亮光晕、放射渐变或其他花哨装饰。

## 8. 拳焰释放效果

点击一次“拳焰”按钮后：

- 立即消耗本次拳焰储备；
- 强化持续 `20` 秒；
- 按钮在强化期间显示剩余时间；
- 主角经普通战斗攻击判定造成的伤害变为 `2` 倍；
- 普通拳、腿、升龙拳、空中踢、弹射飞踢和空中飞连踢均使用该倍率；
- 普通拳击动作与命中特效显示拳焰；
- 抓摔固定伤害、手榴弹、战锤和队友伤害不受拳焰倍率影响；
- 计时结束后伤害和拳击表现恢复正常。

拳焰、腿焰不再是永久技能。空中飞连踢自身仍固定保留腿部火焰表现，不依赖拳焰道具。

## 9. 关卡结束、失败与清理

- 进入新关卡或重新开始关卡时，腰间投掷物、剩余战锤次数、未释放拳焰和拳焰剩余时间全部重置。
- 未拾取的手榴弹、战锤和拳焰不会在胜利结算时自动转换为账号资源。
- 未拾取的金币、鸡腿和果实会在胜利时自动收取。
- 当前全队失败流程会先把金币、鸡腿和果实转入失败结算并把当前显示数量清零；选择放弃掉落并返回，资源不会保留。
- 长时间运行时，已经拾取或消耗的地图掉落会从运行列表清理，避免无效对象持续占用内存。

## 10. 设计原则

- 账号资源与本关战术道具分离，避免把一次性战斗优势永久带入下一关。
- 投掷物要求主动拾取和主动释放，保留临场决策。
- 拳焰使用自动拾取和独立按键，避免与腰间投掷物、石门操作争抢按钮。
- 石门始终具有最高交互优先级，防止地下探索被道具操作阻塞。
- 账号资源和正式闯关奖励以服务端结果为准，客户端视觉和按钮状态不能作为可信结算依据；场内伤害与击飞则由当前游戏运行时计算。

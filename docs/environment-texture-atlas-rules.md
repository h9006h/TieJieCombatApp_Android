# 铁街格斗环境贴图生成规则

## 2x2 图集契约

- 图集必须是正方形，宽高均为偶数，严格等分为四格，不得包含边框、分隔线或留白。
- 左上 `A`：普通墙，可连续平铺为 `A -> A`。
- 右上 `B`：攀爬墙，只能在真实攀爬区使用，必须支持 `A -> B -> A`。
- 左下 `C`、右下 `D`：两种地面，必须支持 `C -> D -> C`。
- 四格必须使用相同像素密度、透视、光源方向、对比度和材质尺度。

## 左右边缘规则

- 每格左右各 `15%` 是安全过渡区，只能放连续、均匀的基础材质。
- 安全区禁止暗角、投影、亮边、立柱、门框、大裂缝、污渍中心或其他视觉焦点。
- 默认禁止任何横向电线、管道、栏杆和地缝进入安全区，避免平铺后出现半截结构。
- 如果业务必须让线性结构跨边缘，左右边缘的位置、宽度、颜色、明暗和切线必须逐像素对应；不能仅靠“看起来接近”。
- 不得使用阴影、黑带、立柱或模糊矩形遮盖生成失败的接缝。

## 攀爬区规则

- 攀爬构件只允许出现在 `B` 格中央 `50%` 范围内，左右安全区必须与 `A` 的基础墙面一致。
- 梯子或攀爬横档必须垂直、清晰、从水面附近向上延伸，并与游戏中的 `climbX` 对齐。
- `B` 格不得随机平铺；普通墙先用 `A` 铺设，再仅在攀爬坐标覆盖一格 `B`。

## 水淹区氛围

- 墙面使用海上钢筋混凝土、盐析、剥落灰绿色涂层和少量锈迹，不使用室外天空、窗户或门洞。
- 地面使用冷青色浅水、统一水深和统一浅透视；左右安全区不得放排水口、石块或明显地缝。
- 所有格子的边缘亮度必须均匀，不能通过两侧变暗营造纵深。

## 生成与验收流程

1. 生成时逐格声明 `A/B/C/D` 职责，并原样附上本规则中的边缘禁区要求。
2. 生成结果不得直接接入。先运行 `scripts/validate-atlas-seams.py` 生成拼接预览。
3. 墙面预览必须检查 `A|A|B|A`；地面预览必须检查 `C|D|C`。
4. 任何边缘阴影、半截线性结构、亮度跳变、水位变化或透视跳变都判定为失败，优先重新生成或定点编辑素材。
5. 只有拼接预览通过后才更新 `game-assets.js`，并确认运行时代码只在攀爬区使用 `B`。

# 铁街格斗环境贴图生成规则

## 游戏场景名词约定（已与用户确认）

- **沙漠外部 / 外面**：角色尚未进入暗坑时所在的沙漠地表场景，包括道路和地面层；不是地下空间，也不是暗洞入口贴图本身。
- **外部地面**：沙漠外部可行走区域使用的基础沙土地面材质。要求“暗洞内部外室地面和外部地面保持一致”时，指两处使用同一种基础沙土地面材质；暗洞内仍可叠加整体压暗，不代表地下必须与室外亮度相同。
- **路上暗坑 / 沙漠暗坑**：位于沙漠外部道路上的地表洞口，是玩家在地面上看到并可能跌入的入口。它只指洞口及洞缘的外观，不等于整个地下暗洞，也不指地下房间的地面。
- **沙漠暗洞**：从沙漠暗坑进入后形成的整套地下空间，包含自然岩壁过渡区、外室、内部房间、地面、出入口和攀爬出口。
- **暗洞内部外室**：暗洞内部靠近入口或出口、与中间封闭房间相连的自然岩壁过渡空间；在当前地堡式结构中主要对应首尾两间石质区域及其向外延伸的开放通道。它仍属于地下，不是沙漠外部场景，也不是中间的居住或设施房间。
- **普通墙 / 非攀爬墙**：只承担环境背景表现、没有攀爬功能的连续墙面。不得因为画有类似梯子、规则凸点或密集树根而让玩家误以为可以攀爬。
- **攀爬区 / 攀爬墙**：与游戏真实 `climbX` 和攀爬判定对应的局部墙段。攀爬贴图只覆盖这一段，粗树根、抓点或横档用于向玩家明确传达“这里可以攀爬”，不能随机铺到普通墙上。
- **街区攀爬范围**：街区地表没有攀爬区；从街区暗坑进入地下暗层后，只有最右端出口处的一小段墙是攀爬区。该贴图必须对齐真实 `climbX`，不得跟随为了填满画面而向外延长的背景墙边界移动。
- **楼梯 / 台阶**：连接两个可行走高度的真实通行结构，不是沙丘、斜坡或只有外观的背景装饰。沙漠楼梯只使用沙漠地形图集右下格的石阶贴图，不再用 Canvas 图形仿画台阶；贴图只替换视觉表现，不得改变原有通行范围、世界坐标或碰撞判定。
- **贴图**：预先生成并加载的位图素材；“恢复贴图”默认只恢复视觉表现，不改变洞口、楼梯、地面或攀爬区的玩法数据。
- **程序绘制**：由游戏画布代码实时绘制的形状、渐变和线条。除非需求明确要求玩法变化，否则用程序绘制替换贴图或仿造贴图时，同样只能改变视觉表现。

## 2x2 图集契约

- 图集必须是正方形，宽高均为偶数，严格等分为四格，不得包含边框、分隔线或留白。
- 左上 `A`：普通墙，可连续平铺为 `A -> A`。
- 右上 `B`：攀爬墙，只能在真实攀爬区使用，必须支持 `A -> B -> A`。
- 左下 `C`、右下 `D`：两种地面，必须支持 `C -> D -> C`。
- 四格必须使用相同像素密度、透视、光源方向、对比度和材质尺度。

### 沙漠地形图集的既有格位

- `desert-yardang-terrain-2x2-v1.jpg` 是已投入使用的专项地形图集：左上为沙土地面、右上为石板地面、左下为层状岩壁、右下为淡金色石阶。
- 沙漠楼梯必须直接读取右下石阶格，并按真实楼梯梯形范围裁切；不得叠加程序绘制的踏面、立面、裂纹、边缘线或颜色渐变。
- 拉伸和裁切只能改变贴图显示尺寸，不能改变楼梯碰撞、台阶高度、起止坐标和可通行范围。

## 左右边缘规则

- 每格左右各 `15%` 是安全过渡区，只能放连续、均匀的基础材质。
- 安全区禁止暗角、投影、亮边、立柱、门框、大裂缝、污渍中心或其他视觉焦点。
- 默认禁止任何横向电线、管道、栏杆和地缝进入安全区，避免平铺后出现半截结构。
- 如果业务必须让线性结构跨边缘，左右边缘的位置、宽度、颜色、明暗和切线必须逐像素对应；不能仅靠“看起来接近”。
- 不得使用阴影、黑带、立柱或模糊矩形遮盖生成失败的接缝。

## 攀爬区规则

- 攀爬构件只允许出现在 `B` 格中央 `50%` 范围内，左右安全区必须与 `A` 的基础墙面一致。
- 梯子或攀爬横档必须垂直、清晰、从水面附近向上延伸，并与游戏中的 `climbX` 对齐。
- `B` 格不得随机平铺；普通墙先用 `A` 铺设，再仅在攀爬坐标覆盖一格 `B`。
- 生成攀爬区贴图时，攀爬核心两侧的墙面也要加入符合当前场景材质的合理可抓取物，用来突出完整的
  攀爬路线：混凝土或砖石墙使用裸露钢筋、凸出的断砖和稳固石块；岩壁使用突出的岩块、岩缝和粗大
  树根；森林、潮湿洞壁等自然场景使用粗大树藤、盘根和结实枝根。可抓取物应从下至上形成连续、清楚、
  可信的落手点，不能只在正中央孤立放置一架梯子。
- 两侧可抓取物仍属于攀爬区贴图的一部分，必须直接制作进 `B` 格或专用攀爬贴图；不得由运行时代码
  补画。它们可以向攀爬核心两侧扩展，但不得进入每格左右 `15%` 的拼接安全区，也不得出现在普通
  `A` 墙上，以免玩家误判其他墙面同样可以攀爬。
- 每个暗坑在玩家落入地下后的入口墙面必须直接设置一个攀爬区，并将攀爬贴图中心与该入口的实际
  判定坐标对齐；玩家可以在入口处原路爬回地面。暗坑另一端原有的攀爬出口继续保留，因此成对暗坑
  的地下空间同时具有入口攀爬区和出口攀爬区，两处都必须使用对应场景的 `B` 格或专用攀爬贴图。
- 攀爬区的墙面、抓点、钢筋、横档、梯子、树根和藤蔓必须全部来自预制贴图；运行时代码不得再用
  Canvas 路径、矩形、渐变、描边或文字箭头补画、仿造或强化攀爬构件。
- 程序只负责选择正确贴图、裁切安全边缘、对齐 `climbX` 和控制覆盖范围，不得在贴图上叠加程序绘制的
  梯子、树根、藤蔓、抓点、轮廓线、亮线或“↑”提示。
- 贴图加载失败时不得回退到程序绘制的攀爬区；应保持普通墙面并记录素材问题，避免不同设备看到两套外观。
- 独立攀爬贴图和图集 `B` 格绘制时必须内裁源图边框，并向相邻普通墙轻微重叠，禁止把源图白边、图集
  分隔线或插值产生的半透明亮线带入画面。

### 全地图白线检查

- **铁街旧巷**：暗洞攀爬块使用洞壁攀爬贴图，左右边缘不得出现亮色矩形线。
- **敦煌荒壁**：使用沙漠岩壁树根攀爬贴图，必须裁掉原图四周浅色边框。
- **长城烽燧**：只使用长城坍塌攀爬贴图，不得额外程序绘制砖块、树根、描边或箭头。
- **天空避难所**：只读取避难所墙面图集的 `B` 格，并避开图集外框和中间分隔线。
- **水中避难所**：只读取水淹墙面图集的 `B` 格，不得额外叠加程序藤蔓或钢筋。
- **迂回密林**：使用现有贴图型坍塌/根系攀爬标识，不得由程序生成树根。
- 验收时分别观察攀爬块的左、右、上、下四边；任何连续白线、浅色矩形框、图集分隔线或一像素闪线
  都视为失败。检查必须同时覆盖整数缩放和非整数缩放，避免只在某一设备分辨率下正常。

## 水淹区氛围

- 墙面使用海上钢筋混凝土、盐析、剥落灰绿色涂层和少量锈迹，不使用室外天空、窗户或门洞。
- 地面使用冷青色浅水、统一水深和统一浅透视；左右安全区不得放排水口、石块或明显地缝。
- 所有格子的边缘亮度必须均匀，不能通过两侧变暗营造纵深。

## 生成与验收流程

1. 生成时逐格声明 `A/B/C/D` 职责，并原样附上本规则中的边缘禁区要求。
2. 生成结果不得直接接入。先运行 `scripts/validate-atlas-seams.py` 生成拼接预览。
3. 墙面预览必须检查 `A|A|B|A`；地面预览必须检查 `C|D|C`。
4. 任何边缘阴影、半截线性结构、亮度跳变、水位变化或透视跳变都判定为失败，优先重新生成或定点编辑素材。
5. 只有拼接预览通过后才更新 `game-assets.js`，并确认运行时代码只在攀爬区使用 `B`。

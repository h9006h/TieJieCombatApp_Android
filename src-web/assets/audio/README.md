# 铁街格斗原创音频

本目录中的音乐和音效由 `tools/generate_original_audio.py` 从零合成。

- 不包含第三方录音、采样包、歌曲片段、影视或游戏素材。
- 音乐旋律、低音进行、鼓点和音色参数均写在生成器中。
- `audio-manifest.json` 保存采样率、用途、时长和 SHA-256，便于验证版本与来源。
- 修改生成器后重新运行脚本即可确定性地重建全部音频。

关卡音乐位于 `music/`，采用 12 小节“引子—主段—变化—留白—渐强—高潮”结构，并以 22.05 kHz 立体声输出。整体方向为武侠网游配乐：持续揉弦弦乐群、琴弦物理反馈生成的古筝/琵琶式拨奏、笛箫、堂鼓、铜锣和原创空间混响。每关都有跨越两个小节并交叠淡化的持续和声底床。敌人和主角受击音效位于 `sfx/`，每种敌人有两个轮换变化；主角拳击以皮肉钝响为主，斧头与刺客命中主角时使用独立的合成割裂音。

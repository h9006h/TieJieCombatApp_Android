# 避难所格斗原创音频

本目录中的音乐和音效从零合成。当前唯一的背景音乐《铁血沸腾》由 `scripts/generate_battle_music_preview.py` 生成；音效由 `tools/generate_original_audio.py` 生成。

- 不包含第三方录音、采样包、歌曲片段、影视或游戏素材。
- 音乐旋律、低音进行、鼓点和音色参数均写在生成器中。
- `audio-manifest.json` 保存采样率、用途、时长和 SHA-256，便于验证版本与来源。
- 《铁血沸腾》的生成器已经随项目保存，可以确定性重建。

关卡音乐位于 `music/`。《铁血沸腾》为 44.1 kHz、148 BPM 的 32 小节东方战斗管弦乐，使用长线弦乐旋律、战鼓、铜管和高潮唢呐。所有关卡统一播放这首音乐。敌人和主角受击音效位于 `sfx/`，每种敌人有两个轮换变化；拳脚命中由播放器补充低频皮肉冲击层，斧头与刺客命中主角时保留独立的割裂音。
